# Vista iPhone Preview

Esta variante se superpone únicamente durante un empaquetado separado. No modifica el frontend ni el instalador de escritorio originales.

Después de instalarla en la computadora principal, conecte el iPhone a la misma red Wi-Fi y abra en Safari la dirección local mostrada al finalizar, por ejemplo `http://192.168.1.50:3000`. Para conservar un icono, use **Compartir → Agregar a pantalla de inicio**.

La computadora principal y MariaDB deben permanecer encendidos. Esta variante habilita únicamente direcciones IPv4 privadas y una regla de Firewall para redes privadas; no expone deliberadamente el POS a Internet.
