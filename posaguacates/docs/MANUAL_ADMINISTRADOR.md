# Manual del administrador

El administrador gestiona usuarios, productos, proveedores, compras, inventario, clientes, cancelaciones, configuración, reportes y respaldos. El stock nunca se edita directamente: use movimiento, compra, venta o cancelación.

Toda cancelación exige motivo, evita repetición y conserva historial. No desactive el último administrador ni Público General. Genere y verifique respaldos periódicamente.

Para registrar una entrada use **Inventario → Proveedores → Nuevo proveedor** y después **Inventario → Compras / Entradas**. La compra incrementa el stock, genera movimientos y actualiza el último costo del proveedor de forma transaccional. Los proveedores con historial se desactivan; no se eliminan físicamente. Consulte `MANUAL_PROVEEDORES.md` y `MANUAL_COMPRAS.md` para el detalle.
